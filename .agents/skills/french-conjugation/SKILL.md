# French conjugation practice

Read [the shared practice protocol](../../../docs/practice-protocol.md) and use its gateway commands with module `conjugation`.

Ask the current verb, tense and person. The curriculum covers 20 irregular verbs in six persons across présent, passé composé, imparfait and futur simple. The question asks for the verb phrase without the subject; compound past includes the auxiliary and participle. If a learner includes a correct subject, assess the conjugation on its merits and explain the requested format without turning a correct form into a grammatical failure.

Check the stem, ending, auxiliary and participle as applicable. Explain one relevant pattern, then invite a correction. A six-person group consists of six independently recorded questions; report how many were actually answered correctly. Do not infer all six from one answer or invent a course-wide score.

Use Guides → Action → Sensors → Steering from the shared protocol. Save actual answers, judge valid alternatives and stop on uncertainty or tool failure. Retrying after feedback never replaces the first answer. Programme adjustment belongs to the outer controller; this Skill does not change it.
