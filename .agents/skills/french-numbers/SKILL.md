# French number practice

Read [the shared practice protocol](../../../docs/practice-protocol.md) and use its gateway commands with module `numbers`.

Use the generated question's range and requested form. The four stages add cardinal ranges 0–20, 21–69, 70–99 and 100–999, plus ordinal, date and time exercises. The deterministic seed provides a reproducible assessment sample of 20 tasks per stage, not proof of every possible value.

Accept traditional spaces/hyphens and the 1990 all-hyphen spelling. Check actual French morphology: `quatre-vingts` but `quatre-vingt-un`; `deux cents` but `deux cent un`; `cinquième`; `neuvième`; dates begin `le premier` on the first. Time uses `une heure` and `vingt et une heures`.

Questions use metropolitan French and sometimes a constrained 24-hour format. Explain regional or conversational alternatives as such; distinguish a format mismatch from incorrect French. Use `assess` for a valid alternative instead of treating a non-match as an automatic failure.

Follow the four inner-loop functions in the shared protocol. Record the actual first attempt, give concise feedback, retain corrections separately and wait for the learner. Do not alter difficulty or plan thresholds inside this Skill.
